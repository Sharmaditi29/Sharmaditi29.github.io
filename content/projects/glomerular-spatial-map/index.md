This project turns a research trajectory into a compact, explorable web artifact. The central map is a stylized glomerulus that changes across disease states, with layers for cell populations, pathway arrows, local stress, and anatomy labels.

The content was modeled from the UKE and IMS xenium-cgn workflow and a lightweight derived dataset, so the page stays fast and readable while still pointing back to the real study context.

The live demo is embedded as a standalone project page on this site, which makes it easy to share with collaborators, labs, or anyone curious about research communication on the web.
